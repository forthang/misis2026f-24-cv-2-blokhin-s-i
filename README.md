**FDK** восстанавливает объём по одной орбите. Три `fdk_pos` — три реконструкции
целого ореха по разным положениям источника, а не три плоскости среза.
**full_AGD_50** — итеративная реконструкция по трём орбитам за 50 итераций.
Это качественное опорное изображение.

В скачанных реконструкциях — 501³ вокселей, срез 501×501, значения `float32`.
При параметрах авторской сетки шаг составляет 0,1 мм.

### 1. Lagerwerf et al., 2020 — влияние реконструкции на сегментацию

[A Computationally Efficient Reconstruction Algorithm for Circular Cone-Beam Computed Tomography Using Shallow Neural Networks](https://doi.org/10.3390/jimaging6120135).
[Полный препринт](https://arxiv.org/html/2010.00421),
[код авторов](https://github.com/MJLagerwerf/nn_fdk).

**Заметки.**  NN-FDK-реконструкция, но для оценки 
классическая сегментация: гауссов фильтр, watershed, и тд.
Опорные маски через SIRT+ реконструкции, а не ручной разметкой. 

**Чеб сделал.** Сравнить пороги, Multi-Otsu и пороги с watershed на размеченных
 AGD; Multi-Otsu потенциальный вариант. На части для настройки проверить
`sigma = 0; 0,5; 1` пиксель. применить к трём FDK.
До использования общей ручной маски проверить совпадение координат объёмов.

**Пойму:** насколько ошибки реконструкции ухудшают маску и помогает ли
добавление пространственных правил. БЕз дообучения NN-FDK 

### 2. Bernard et al., 2020 — область ореха и целостность скорлупы

[3D characterization of walnut morphological traits using X-ray computed tomography](https://doi.org/10.1186/s13007-020-00657-7).

**Особенность.** Челы выделяли ткани для измерения морфологии ореха,
используя пороги и watershed. Метод зависел от целой скорлупы; повреждённые
ОРЕХИ сегментироваться неправильно(наверное) и исключались. Они делали через
Avizo, MATLAB и скрипты; готовый ручной Dice-бенчмарк не нашел.

**Делаю.** Сравнить Multi-Otsu по всему срезу и внутри автоматически
найденной области ореха. Проверить замыкание внешнего контура с радиусом
`0, 1, 2` пикселя. Включить верхушку, центр, основание и FDK со слабыми контурами. Не заполнять отверстия в маске ядра.

**пойму:** помогает ли исключение внешнего воздуха выбирать пороги
и немного о замкнутой скорлупе.

### 3. Amézquita et al., 2024 — автоматические маркеры тканей

[Allometry and volumes in a nutshell: Analyzing walnut morphology using three-dimensional X-ray computed tomography](https://doi.org/10.1002/ppj2.20095).
[Код walnut_tda](https://github.com/amezqui3/walnut_tda),
[данные](https://doi.org/10.5061/dryad.ngf1vhj09).

**заметка**
После стандартизации интенсивностей метки задаются по яркости и геометрическим
признакам, затем применяется watershed. Открытые маски являются результатом
обработки; их нельзя автоматически считать правдой но хочется.
Полезны раздел обработки изображений и рисунок самый первый.

**Опыт.** Для одного watershed сравнить метки только по интенсивности
и метки с отступом от предполагаемых границ на `0, 1, 2` пикселя.
Фильтр, карта градиента и постобработка = const. Проверить сохранение
тонких участков ядра и перенос на FDK. 

**Что выясняем:** улучшаются ли границы благодаря более надёжным начальным меткам.
Расстояние до границы в 2D не равно толщине ткани в 3D!!! почему то не очев;

### 4. Chan и Vese, 2001 — слабые границы

[Полный текст](https://www.sfu.ca/~rpyke/research/vese_chan.pdf).

**ЗАмтека.** Контур ищется по статистике областей внутри и снаружи,
=> резкий перепад яркости не факт. Воздух и скорлупа образуют
неоднородный фон, который двухфазная модель плоъо видит.

**Сделать** пороговую маску через `skimage.segmentation.chan_vese`.
На части для настройки проверить `mu = 0,05; 0,2; 0,5`,
`lambda1 = lambda2 = 1`, максимум 300 итераций при фиксированной нормализации 0–1.
Сравнить две инициализации: исходную маску и слегка суженную.
Дополнительный тест — размытие AGD с `sigma = 0; 0,5; 1; 2` пикселя совместно с первым экспериментом.

**Выяснить:** помогает ли уточнение слабых границ без потери тонких деталей.
Гладкий контур не равно точная сегментация.

### Инженерные методы

| Метод | Зачем проверять | Ограничение |
|---|---|---|
| Otsu / Multi-Otsu | Простой ориентир по интенсивности, стартовая маска | Группы яркости не обязательно соответствуют тканям |
| Фильтры и морфология | Шум, внешняя область ореха, мелкие ложные островки | Могут удалить тонкие части ядра и заполнить реальные пустоты |
| Watershed с маркерами | Разделение тканей с начальными надёжными метками | Ошибочные метки и слабые границы приводят к неправильным областям |
| Chan–Vese | Уточнение контура при слабом перепаде яркости | Двухфазная модель плохо описывает неоднородный фон из воздуха и скорлупы |
| Random Walker | Распространение меток с учётом связей пикселей | Зависимость от расположения маркеров и параметра `beta` |
| Random Forest по признакам | Обучение по яркости, краям и текстуре | Требует размеченных данных; выделять как отдельный обучаемый режим |



### Современные подходы в целом

| Направление | Роль в сравнении | Условия |
|---|---|---|
| [U-Net / nnU-Net](https://doi.org/10.1038/s41592-020-01008-z) | Обучаемая 2D/3D база | Ручные маски, разделение по целым орехам, по бюджету не тяну как будто |
| [SAM 2](https://github.com/facebookresearch/sam2), [SAM 3](https://github.com/facebookresearch/sam3) | Сегментация по подсказкам; распространение маски в последовательности | Фиксировать веса, подсказки и время исправлений |
| [MedSAM](https://doi.org/10.1038/s41467-024-44824-z), [MedSAM2](https://github.com/bowang-lab/MedSAM2) | Модели медицинской сегментации | Перенос с человеческой анатомии на орехи интересно проверить как туда сюда гонять|
| [SAM-Med3D](https://doi.org/10.1109/TNNLS.2025.3586694) | Интерактивная сегментация объёма | Дополнительный 3D-контекст и вычислительные ресурсы |
| Псевдомаски и адаптация на малой разметке | Возможное продолжение после базовых опытов | Независимый ручной тест; ошибки псевдомасок не должны стать эталоном |

В [работе Ma et al., Food Control, 2026](https://doi.org/10.1016/j.foodcont.2025.111879)
по КТ орехов в аннотации сообщаются Dice **0,89 для ядра** и **0,95 для ореха целиком**
при использовании U-Net.

| Показатель | Что измеряет |
|---|---|
| Dice | Совпадение областей ядра |
| Boundary F1 | Совпадение контуров при заранее заданном допуске |
| HD95 | 95-й процентиль расстояний между границами; зафиксировать симметричный способ расчёта |
| Ошибка площади и сбои | Пропуски, ложные области, несходимость, пустые ошибочные маски |

Для пилота можно проверить допуски границы 1 и 2 пикселя; при шаге 0,1 мм
это 0,1 и 0,2 мм. Их нельзя выбирать задним числом ради лучшего результата.
Для пустых масок нужно заранее установить соглашения: одна ошибочно пустая
маска даёт Dice 0, а расстояние границ не определено. ПО метрикам см.
[Metrics Reloaded, 2024](https://doi.org/10.1038/s41592-023-02151-z).
